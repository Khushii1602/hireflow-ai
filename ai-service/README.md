# AI service (planned)

This folder is reserved for a Python service that may later support resume text extraction and transparent skill matching.

No parsing or ranking logic is implemented yet. The first milestone is to define a safe input/output schema, evaluate extraction quality on permitted sample data, and document limitations before integrating any model.

Planned modules:
- Resume text extraction
- Skill normalisation
- Job requirement parsing
- Explainable candidate-to-role comparison

Any future output is intended as decision support for recruiters, not an automated hiring decision.
