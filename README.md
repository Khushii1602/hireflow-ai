# HireFlow AI

A recruitment workspace for organising job openings, candidate profiles, and application progress.

**Status:** Starter implementation · early development

## What is in this repository

- A responsive React recruitment dashboard preview.
- A sample application pipeline and candidate table using illustrative data.
- An Express API starter with a `GET /api/health` endpoint.
- A reserved folder for a future Python-based AI service.

The frontend data is currently hard-coded. Authentication, job and candidate persistence, resume upload, and AI processing are not implemented. Match scores shown in the preview are illustrative and are not generated by a model.

## Tech stack

- **Frontend:** React, Vite, JavaScript, Lucide icons
- **Backend:** Node.js, Express
- **Database (planned):** MongoDB with Mongoose
- **AI service (planned):** Python

## Run locally

Use Node.js 18 or newer.

**1. Start the API**

```bash
cd server
npm install
```

Copy `.env.example` to `.env`, then run:

```bash
npm run dev
```

The API starts on port `5001`. Check it at `http://localhost:5001/api/health`.

**2. Start the frontend** in a second terminal:

```bash
cd client
npm install
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:5173`).

## Responsible AI direction

Any future matching feature should provide transparent reasons for a suggested match, avoid sensitive candidate attributes, and support—not replace—human recruiter judgement. No automated hiring decision or model-generated score is active in this starter.
